# JavaScript Class — Beginner to Full-Stack (Next.js)

A complete, two-part curriculum for taking a student with **zero programming experience** to building and deploying full-stack web applications with Next.js.

## Part 1 — JavaScript Fundamentals & Frontend

Files `00`–`18` in this folder. Start with [00-TEACHING-GUIDE.md](00-TEACHING-GUIDE.md).

| Phase | Lessons |
|-------|---------|
| Core programming | 01 Intro & setup · 02 Variables & types · 03 Operators · 04 Conditionals · 05 Loops · 06 Functions · 07 Arrays · 08 Objects · 09 Built-in methods · 10 Errors & debugging |
| The browser | 11 DOM · 12 Events · 13 Forms & localStorage |
| Modern & async | 14 Modern JS (ES6+) · 15 Async · 16 Fetch & APIs |
| Extras | [17 Projects](17-PROJECTS.md) · [18 Cheat sheet](18-CHEATSHEET.md) |

## Part 2 — Backend (Node/Express) → React → Next.js

## Lesson format

Every lesson has: a goal, plain-language explanations with runnable examples, a ⚠️ common-mistakes section, ✅ classwork (done together), 📝 homework (done alone), and a 🔑 key-words table.

One project threads through Part 2 — a **Tasks app** — rebuilt at each layer: JSON-file CLI → Express API → SQLite → Prisma → auth → deployed → React frontend → full-stack Next.js app with cookie sessions on Vercel.
